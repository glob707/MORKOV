# MARKVI

Плагин [BetterDiscord](https://betterdiscord.app), который раскладывает голоса участников звонка по стереопанораме. Когда в большой компании говорят несколько человек сразу, голоса не сливаются в кашу: кто-то слышен слева, кто-то справа.

Главная функция — динамическая панорама: несколько слотов (по умолчанию 5) занимают те, кто сейчас говорит; замолчавший через пару секунд уступает место следующему.

> **Статус: в разработке.** Сейчас плагин только загружается и пишет в консоль. План и архитектура — [docs/PROJECT_DEFINITION.md](docs/PROJECT_DEFINITION.md).

## Важно знать

- **Нужны наушники.** В колонках панорама почти не слышна.
- **BetterDiscord — клиентский мод, он нарушает условия использования Discord.** Баны за это редкие, но возможны. Решайте сами, особенно если вы стример.
- Проверяется на macOS. Windows должна работать, но не тестируется.
- Плагин ничего не отправляет в сеть. Раскладка и настройки хранятся только у вас на компьютере; другим участникам звонка ничего ставить не нужно.

## Установка

1. Установите BetterDiscord.
2. Скачайте `MARKVI.plugin.js` и положите в папку плагинов (Настройки → BetterDiscord → Плагины → «Открыть папку плагинов»).
3. Включите MARKVI в списке плагинов.

## Разработка

Нужен Node.js 22+.

```sh
npm install
npm run build        # собрать dist/MARKVI.plugin.js
npm run deploy       # собрать и скопировать в папку плагинов BetterDiscord
npm test             # юнит-тесты
npm run ci           # всё, что проверяет CI: типы, линтер, тесты, сборка, проверка бандла
```

Логи плагина — в консоли Discord (Cmd+Option+I на macOS, Ctrl+Shift+I на Windows) с префиксом `[MARKVI]`.
